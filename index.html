THE PHILOSOPHY

Enough to dive into.
Not enough to overwhelm.

Modern baseball provides an enormous amount of data. TimBaseball takes a deliberately narrower approach: start with a few solid core measurements, build a consistent profile, then add context where it helps.

The result is an analytics system designed to help you see the player without making you stare at the entire spreadsheet.
